# Quirk context continuity

Status: candidate contributor guidance. Authority effect: none.

Quirk remains a creative medium, capability ecosystem, and participatory world.
This repository applies that breadth to **new project, module, and feature guidance**.

Read [the local profile](.quirk/context-profile.json) for its exact contract digest,
observed base, applicable requirements, and evidence limits. The candidate source is
[Quirk Core context continuity](https://github.com/Quirk-Systems/quirk-core/blob/codex/context-continuity-20261014/contracts/context-continuity/v0.1/README.md).

## Apply here

- New children inherit a context profile or declare a local difference.
- Provide private or observational paths before adding participation metrics.

Preserve originals, useful differences, and source lineage. Untried means unknown
in value, not unsuccessful. Scope preferences and honor withdrawal or task-specific
bypass. Explain material selection and omissions without exposing private metadata.
Measure actual correction effort and interruptions only when voluntarily reported.

## Inherit and verify

Features, modules, components, files, styles, and documentation inherit this profile
when relevant. Declare a local difference only when behavior, audience, or permissions
actually differ. Inspect source revisions at task start and resume. Keep finished
works historical; add successors or linked corrections. Do not recursively overwrite
local instructions or creative source material.

A file or profile does not prove a host loaded it. Record authored, delivered, loaded,
behavior-tested, admitted, and deployed separately. No scheduler, service connection,
or production adoption is installed by these files. Evaluate the acceptance cases
on the affected application before claiming runtime compliance. Roll back this candidate
profile independently while preserving source history and live withdrawals.

When copying this scaffold, replace the source repository identity and observed
base in the profile with the new project’s actual values. Keep the inherited
contract digest until an intentional migration; do not invent a passing adoption
receipt. Review private, observational, and departure paths in the new UI.
