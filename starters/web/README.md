# Quirk Web Starter

A small, independent Next.js starting point with a local idea preview. The
preview is an example of candidate-first interaction; it saves and sends
nothing. Replace it with the experience your project needs.

Requires Node 22.22.2 or later and npm. From this directory:

```sh
npm ci
npm test
npm run dev
```

Open http://localhost:3000. `npm run build` creates a production build; it does
not deploy the app. No database, authentication, billing, AI provider, or
Quirk OS runtime is preconfigured. Add only what the project needs, with its
own configuration, permissions, evidence, and review.
