# Quirk Applications

Application surfaces consume stable package interfaces and registries. They do not own canonical definitions.

- `control/` — operational console for context, capability, authority, execution, proof, assets, and signals.
- `docs/` — internal technical and canonical documentation experience.
- `pages/` — public or shared publishing surface for approved Quirk assets.
- `studio/` — experimental design, generative UI, simulations, and asset production.

The existing root Next.js application remains the compatibility application until a dedicated migration moves it into `apps/control`.
